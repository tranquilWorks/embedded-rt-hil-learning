## Deterministic model and failure contract

- Baseline request is 2.5 V from 0.5 V using a 3.3 V, 12-bit unipolar DAC, 100 us update latency, 250 us
  time constant, 4000 V/s slew rate, 10 mV tolerance, 5 us sample period, 601 points, and infinite deadline.
- The explicit transfer is `L=2^B`, `LSB=V_ref/L`, nearest integer code clamped to `[0,L-1]`, and
  `V_code=code*LSB`. Initial code/voltage are 621/0.5003173828125 V; command code/voltage are
  3103/2.4999755859375 V; maximum code voltage is `V_ref-LSB`.
- Before an accepted update, the active code and held target remain initial. At and after the exact analytical
  latency, the target changes while analog voltage remains continuous. A latch between samples is not rounded
  onto the sample grid.
- With step magnitude `D`, pole `tau`, and slew cap `S`, the model uses `D exp(-t/tau)` when pole-limited. A
  slew-limited step ramps until error `S*tau`, then enters a value- and slope-continuous exponential tail.
- The baseline natural slope is 7998.6328125 V/s, so it slews for 249.91455078125 us. Analytic settling occurs
  1.401207097 ms after the latch and 1.501207097 ms after command; the 5 us grid first observes an all-future
  stay at 1.505 ms.
- The time-constant sweep `[100 250 500 1000 2000] us` holds code, latency, slew, tolerance, and grid fixed.
  The slew-rate sweep `[Inf 8000 4000 2000 1000] V/s` resets the pole and holds code, latency, tolerance, and
  grid fixed.
- `update-not-latched` keeps a completed digital record of code 3103 while active code and analog output stay
  at code 621. This diagnostic does not claim a universal DAC register architecture.
- A deadline exactly at update latency passes. One representable step earlier, 50 us, and zero reject the
  command, expose no recorded code, and keep active target/output initial. This is analytical policy, not
  driver cancellation.
- Calls are state-free; clean inputs are exact computational rollback, clean re-invocation is recovery, and
  malformed calls cannot contaminate later calls. There is no asynchronous cancellation operation.
