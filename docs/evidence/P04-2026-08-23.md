## Deterministic model and failure contract

- Inputs are paired nonnegative synthetic start times and true intervals in microseconds, a positive timer
  tick `q`, a phase `phi` in `[0,q)`, and an integer width `B` from 1 through 32.
- The transparent unwrapped capture is `k(t)=floor((t+phi)/q)` after applying one pair-local scale-aware
  normalization tolerance shared by that pair's start and stop near exact integer tick boundaries. The
  finite count is `c(t)=mod(k(t),2^B)`; unrelated pairs cannot alter one another's tolerance.
- The modular captured delta is `mod(c_stop-c_start,2^B)`. Its primary interval is valid only when the
  unwrapped captured delta is strictly less than one modulus.
- Ideal endpoint timestamp errors are in `(-q,0]`; boundary normalization admits a positive endpoint error
  no larger than the retained shared tolerance in microseconds. Valid interval error is the difference of
  endpoint errors and has magnitude strictly below one tick. Interval error may have either sign.
- A full-modulus or multi-modulus delta is explicitly range-ambiguous: the primary interval and error
  are `NaN`, while the modular alias is retained only for diagnosis.
- The broken case captures count 255 then count 2. Ordinary signed subtraction reports -2530 us, modular
  subtraction reports the valid 30 us quantized interval, and the next non-wrapping pair proves recovery.
- Collection sizes are bounded before value scans, scalar intervals expand only within the one-million-pair
  bound, derived stop times must advance representably, absolute tick indices are bounded, and counter wrap
  period must remain finite.
- Resolution, oscillator accuracy/drift, synchronization and capture latency, execution jitter, overflow
  races, and device-specific register behavior remain distinct.
