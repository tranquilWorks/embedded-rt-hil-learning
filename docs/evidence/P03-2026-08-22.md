## Deterministic model and failure contract

- Inputs are nonoverlapping synthetic request pulses `[arrival, arrival + width)` inside a finite
  observation horizon, all in milliseconds.
- Polling detects only a pulse containing an actual generated poll instant. Its recurrence is
  `next_poll = max(current_poll + poll_period, current_work_finish)`.
- Poll work is the clipped sum of explicit check cost and handler cost for detected requests; its CPU
  fraction is modeled event-handling work, not measured utilization. Totals do not isolate check cost
  when polling and interrupts service different request counts.
- Interrupt capacity is a FIFO abstraction whose bound includes queued plus in-service requests.
- Each accepted interrupt waits for earlier work, dispatch latency, and any mask containing its dispatch
  candidate. Masking does not abort a handler already started.
- An arrival when capacity is full is marked as overrun. Accepted work finishing after the horizon is
  backlog/timeout and is not mislabeled as overrun.
- The broken `[6, 10)` ms mask with capacity one retains the first burst edge, drops the next five, drains,
  and captures the 11.5 ms recovery edge.
- Input collection sizes are bounded before value scans, projected polls are bounded before poll-array
  allocation, and derived times must be finite and resolution-preserving; the model uses monotone cursors
  and bounded loops.
- Scale-aware nearest-boundary normalization preserves half-open pulse, mask, and observation-horizon
  rules, exact interrupt-capacity release, and completion-at-horizon accounting across binary roundoff.
- A transient-level polling miss is not universal: a real peripheral with a sticky flag can retain or
  coalesce requests under a different hardware contract.
