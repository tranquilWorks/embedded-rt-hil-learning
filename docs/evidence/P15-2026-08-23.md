## Deterministic model and failure contract

P15 uses reference event times `[250000 750000 ... 3750000] us`, PPS IDs `0:4`, a `1000000 us` PPS
period, `2500 us` initial local-clock offset, `40 ppm` oscillator skew, and a `1 us` downward timestamp tick.
The governing local clock is `C(t)=b+(1+s*1e-6)t`. Its baseline PPS captures are
`[2500 1002540 2002580 3002620 4002660] us`; event captures are
`[252510 752530 1252550 1752570 2252590 2752610 3252630 3752650] us`.

Raw event errors are `[2510 2530 2550 2570 2590 2610 2630 2650] us`. A one-PPS offset-only correction
leaves `[10 30 50 70 90 110 130 150] us`. Correctly associated first/last anchors recover `2500 us` and
`40 ppm`; governing aligned errors and fit residuals are zero.

Offset `[0 1000 2500 5000 10000] us` yields first raw errors
`[10 1010 2510 5010 10010] us` and final raw errors `[150 1150 2650 5150 10150] us`. After reset, skew
`[-80 -40 0 40 80] ppm` yields four-second drift `[-320 -160 0 160 320] us`, final raw error
`[2200 2350 2500 2650 2800] us`, and offset-only maximum absolute error `[300 150 0 150 300] us`.

The broken case receives PPS IDs `[0 2 3 4]`. Sequence-ID association retains the missing count and still
recovers the ideal affine clock. Arrival-index association substitutes assumed reference coordinates
`[0 1000000 2000000 3000000] us`, estimates `333386.666... ppm`, produces interior residuals near
`666693.333` and `333346.667 us`, and yields event errors
`[-62500 -187500 -312500 -437500 -562500 -687500 -812500 -937500] us`.

A `2000000 us` timeout passes the missing-ID gap by equality. At `1500000 us`, continuation records
lateness and retains all four captures; cancellation retains only ID `0`, censors IDs `2:4`, leaves affine
outputs unavailable/`NaN`, and preserves raw timestamps. Repeating clean pure input is computational
rollback and recovery only.

An eight-quotient-ULP operation-chain guard applies before downward tick flooring, matching P04; a one
gap-scale-ULP adjacent-value policy applies only at positive timeout boundaries. PPS gaps use sequence-ID
deltas times period, not subtraction of absolute epochs. Retained exact, adjacent, four-ULP-late, zero-timeout,
and distinguishably-below-tick cases keep these guards from becoming general rounding. Absolute timestamp
tick indices are limited to `1e12`: without that ceiling, eight ULPs reach at least half a tick near `2^48`,
and a genuinely below-boundary value can be snapped upward in violation of `floor`.

| Oscillator skew | local clock rate error | -200–200 ppm |
| Timestamp tick | downward local capture quantization | 1–1000 us |

### Metrics and units

- input: reference event time and PPS period/timeout/offset/tick (us), sequence ID (count), skew (ppm), and
  action/association (name);
- clock: ideal and quantized local event time (us), rate ratio (unitless), and raw error (us);
- PPS: true/assumed reference time, ideal/quantized local capture, gap, and fit residual (us), plus retained,
  censored, and late flags;
- alignment: availability, estimated rate (unitless), skew (ppm), offset (us), aligned event time, corrected
  error, and offset-only error (us);
- observation: timeout/cancellation flags, deadline/last-capture time (us), and retained/censored counts;
- aggregate: event/received/missing counts, maximum gap (us), raw/offset-only/corrected maximum error (us),
  fit residual (us), and association consistency.

## Changed invariants

- P15 owns an explicit affine local clock `C(t)=b+(1+s*1e-6)t` with microsecond and ppm units.
- Timestamp captures use declared downward tick quantization rather than hidden timestamp precision.
- PPS sequence identity, not received array position, names the synthetic reference epoch.
- First/last retained anchors expose the offset/rate inverse calculation without a fitting toolbox.
- A per-gap timeout uses strict `gap>timeout`; a capture at equality is processed first.
- Tick flooring uses P04's eight-quotient-ULP affine-operation bound; positive timeout equality uses one
  gap-scale ULP, while zero timeout stays strictly zero-tolerance.
- Absolute timestamp tick indices stop at `1e12`, before the eight-ULP guard can span a material fraction of
  one tick and contradict downward quantization.
- PPS gaps derive from sequence-ID deltas times period, avoiding cancellation between absolute epoch values.
- Cancellation retains the pre-timeout prefix, censors later anchors, and never changes raw timestamps.
- `lesson.m` owns the single interactive launch; `experiment.m` no longer creates a duplicate UI and callback
  lifetime when invoked through `launch_lesson`.
- Permanent P15 tests assert P14 implementation and P16's prerequisite edge, but do not freeze P16 status,
  implemented count, latest-module identity, or active-batch state.
