## Deterministic model and failure contract

- Baseline bytes are `[163 85 60 126]` at 115200 binary symbols/s, zero receiver error, 8-N-1,
  zero inter-frame gap, no fault, and an infinite deterministic receive deadline.
- A frame is `[start=0, d0..d7, parity?, stop=1...]`; `N = 1 + 8 + N_parity + N_stop` and
  `T_bit = 10^6 / baud` microseconds.
- Receiver slots are sampled at `(j + 1/2)T_rx` after each qualified start; sample margin is calculated
  against the intended half-open transmitter slot. Exact boundaries are timing-unsafe even when the
  deterministic diagram chooses one side.
- Logic lookup uses the source-frame index plus a bounded frame-local sample offset. Receiver readiness is
  likewise compared as elapsed transmitter-bit times since the last attempted frame, rather than as late
  absolute microsecond timestamps. Retained 10,001-frame regressions require frame 10,000 to match isolated
  positive-margin sampling and near-boundary receiver-busy decisions.
- A post-parity data-bit flip demonstrates detected single-bit corruption, undetected no-parity
  corruption, and even parity's two-bit limitation.
- A forced-low stop in frame 2 causes one framing error, removes frame 3's immediate falling start edge,
  and permits frame 4 recovery after frame 3 returns the line high.
- The optional absolute deadline includes an exact final-sample boundary and rejects a frame just beyond
  it. It is not a device wait or inter-byte packet timeout. Asynchronous cancellation is not applicable.
- Calls are state-free; restoring clean inputs is exact rollback, while a later independent correct frame
  is recovery. Rejected calls cannot contaminate later calls.
- The receiver qualifies only known transmitter frame starts; it does not model false acquisition on data
  edges, oversampling filters, metastability, device status flags, packet framing, or voltage behavior.
