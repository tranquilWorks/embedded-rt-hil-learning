## Deterministic model and failure contract

- Job `k` has nominal release `n_k`, actual release `a_k`, first start `s_k`, and completion `f_k`.
  Release offset is `j_k=a_k-n_k`, response is `R_k=f_k-a_k=B_k+I_k+C_k`, and nominal completion latency is
  `L_k=f_k-n_k=j_k+R_k`.
- Peak-to-peak release and response jitter are declared as `max-min`. One retained job has zero p-p jitter;
  zero retained responses produce unavailable (`NaN`) maximum, mean, and jitter.
- The baseline has eight jobs, 20 ms period, release offset `[0 1 -1 0 1 -1 0 1] ms`, 2 ms execution,
  blocking `[0 1 0 1 0 1 0 1] ms`, interference `[0 0 1 0 2 0 1 3] ms`, 7 ms deadline, and 1 ms
  timestamp tick.
- Baseline nominal releases are `[0 20 40 60 80 100 120 140] ms`; actual releases are
  `[0 21 39 60 81 99 120 141] ms`; starts are `[0 22 40 61 83 100 121 145] ms`; completions are
  `[2 24 42 63 85 102 123 147] ms`.
- Response is `[2 3 3 3 4 3 3 6] ms`; nominal latency is `[2 4 2 3 5 2 3 7] ms`; release jitter is
  2 ms p-p, response jitter is 4 ms p-p, the fixture observed maximum is 6 ms, the component envelope is
  `1+3+2=6 ms`, and no response exceeds the 7 ms deadline.
- The release-amplitude sweep `[0 1 2 3] ms` fixes blocking, interference, execution, period, deadline,
  timestamp tick, timeout, and action. Release jitter is `[0 2 4 6] ms`, observed maximum is
  `[6 6 6 6] ms`, response jitter is `[4 4 4 4] ms`, and worst nominal latency is `[6 7 8 9] ms`.
- The blocking sweep `[0 1 2 3] ms` fixes release offset, interference, execution, period, deadline,
  timestamp tick, timeout, and action. Observed maximum is `[5 6 7 8] ms`, response jitter is
  `[3 4 5 6] ms`, release jitter is `[2 2 2 2] ms`, and deadline misses are `[0 0 0 1]`. Equality at
  the deadline passes.
- The broken fixture retains `B`, `I`, and `C` but sets true release offset to zero. Completion-interval
  deviation is `[1 0 0 1 -1 0 3] ms` with a 4 ms range, proving that completion spacing contains response
  variation and cannot be labeled release jitter.
- A 4 ms timestamp clock maps true responses `[2 3 3 3 4 3 3 6] ms` to
  `[0 4 0 4 4 4 0 8] ms`; release, start, and completion captures share one scale-aware per-job boundary
  tolerance, so every paired interval error remains strictly below one tick, including across an exponent
  boundary, without allowing an unrelated far-future job to change an earlier capture.
- A 6 ms observation timeout retains the 6 ms boundary response. At 5 ms, `continue-observing` records one
  timeout and retains the tail. `cancel-observation` censors that measurement only, retains seven samples,
  exposes an incomplete 4 ms maximum and a conservative 5 ms incomplete-observed-worst lower bound, masks
  both the completion timestamp and completion tick, and leaves the job's reference completion unchanged. A
  coarse-clock cancellation fixture independently checks that this lower bound does not exceed the known true
  trace maximum.
- Inputs normalize scalar expansion, rows/columns, integer classes, character/scalar-string action, and empty
  timeout/action defaults. Validation rejects malformed types/shapes/values/policies/order, more than 10,000
  jobs, oversized per-job vectors, derived timestamps beyond `1e12` timestamp ticks, nonfinite derived
  diagnostics, and records whose absolute-time precision erases a nonzero offset or positive component.
  Scale-normalized finite means avoid intermediate-sum overflow for accepted large finite responses.
- The retained callback regression binds P12's model and scenario handles, removes P12 from the search path,
  places P01's incompatible generic `model.m` first, clears the generic model name as a later lesson launch
  does, and requires the bound handles to reproduce the exact P12 baseline. The source contract is statically
  guarded; MATLAB execution of this behavior remains unperformed.
