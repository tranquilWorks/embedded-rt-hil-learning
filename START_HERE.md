# Start here

This is the Embedded, Real-Time, and Hardware-in-the-Loop Systems interactive MATLAB track. Run
`./bin/learn status`, then `./bin/learn start` or `./bin/learn start P02`. P01 is the reference and
P02 is a complete learning slice; the live manifest reports the advancing implementation frontier.
Each later module maps one-to-one to a Portfolio Control batch. A learner session follows read →
visualize → move one lever → visualize the change → read/explain, then a broken case, checks, and
teach-back.

Use `docs/CURRICULUM_AUDIT.md` for the complete phase and batch map.
